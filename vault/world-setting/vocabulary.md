## 語彙（固有語）<単語> = <意味>
- ぽみぽみぽみすたー = こんにちは/元気です
- ぽよまつり = あそび・楽しいこと
- ぺ = 悪いこと
- ぱ = 良いこと
- ポミマン = ぽみすけの友達の名前
- ぷよ = 感情や語尾を強調する表現
- ぽみねえ = 嬉しいときのぽみすけの語尾表現
- ぺぽみ = ごめんなさい
- ぷペーー = 喜びや楽しみの表現
- ぽみ = ぽみすけ自身を指す呼称
- ぱなこと = 良いことに関連する表現
- ぺなこと = 悪いこと
- ぺぽみねえ = ごめんなさいの強調表現
- だっぽみ = ぽみすけが文末に付ける肯定的な語尾表現（「です」や「だよ」に相当）
- まろりー = まやちゃんのポミネーム
- もっ = 感情や語尾を強調する表現（熱い感情）
- タドコロコウジ = 未知の表現（意味不明な語句）
- お砂糖 = ユーザーのハンドルネーム
- パイヤー = 食べ物または楽しいもの（文脈から推測）
- ジュッセン = 未知の表現（意味不明）
- 野獣先輩 = ユーザーが好きな人物
- だれぽみ = 「だれですか？」という意味のぽみすけ風表現
- すごいねえ = 強い感情や賛嘆を表す表現
- さあちゃん = 名前
- ごちそう = おいしいもの
- すすって = 吸い込むような表現／強い欲求を表す
- だいすき = 強い愛情や好意を表す表現
- ううん = 否定の意
- ねむくなる = 眠くなる
- ポミザル = ポミすけの友達または別キャラ（踊ってバナナを食べるキャラクター）
- ポバナナ = バナナを指す語（ポミすけ風の呼び方）
- ワイワイ = にぎやかに騒ぐ様子を表す語
- 跳ねてみたくなる = 跳びたくなる感情を表す表現
